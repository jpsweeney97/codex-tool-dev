# Change Cycle Plugin Terms

This document applies to local use of the Change Cycle plugin source package in this repository. Source edits here do not prove that an installed plugin cache or running Codex runtime has been refreshed.

The plugin is provided as source for change-impact work: co-change mining before an edit, touchpoint derivation for a new instance, consumer mapping for an interface change, and uniform application of a decided change across many sites. It is provided without warranty. You are responsible for reading the dispositions, maps, and edits a skill produces, for deciding what to commit, and for what the codebase does afterwards.

Change Cycle actions are attended: every edit happens in the working repository in front of the user, and no skill commits, merges, or publishes. Do not treat a clean disposition table, a propagation map, or a completed burndown as release, security, compliance, legal, or operational approval without the appropriate human and project-specific verification.

Installed-runtime behavior, cache refresh, marketplace setup, and runtime proof are separate operational steps from editing this source tree.
