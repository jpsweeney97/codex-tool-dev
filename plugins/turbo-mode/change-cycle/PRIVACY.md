# Change Cycle Plugin Privacy Notice

This document describes the Change Cycle plugin source package in this repository. It does not certify what any installed Codex runtime or plugin cache currently loads.

The Change Cycle plugin provides instructions for taking one code change from its first edit to every site it must reach: mining a file's co-change partners from git history (`co-change-radar`), deriving the touchpoints of a new instance from its siblings' add-commits (`add-an-x-by-example`), mapping the consumers an interface change breaks (`contract-change-propagation`), and applying a decided change uniformly across many sites (`migration-campaign`). It does not create background files, register hooks, run services, or intentionally transmit content to a separate service by itself.

Change Cycle requests may cause the runtime to read local repository files and git history, and to write ordinary edits in the working repository under each skill's own contract, including the burndown record `migration-campaign` keeps for a campaign in progress.

Codex, Claude, account handling, model requests, telemetry, synchronization, and any host application behavior are governed outside this local plugin document.

Review the edits a skill makes before committing them, especially the many-site edits of a migration campaign.
