# Plan Cycle Plugin Terms

This document applies to local use of the Plan Cycle plugin source package in this repository. Source edits here do not prove that an installed plugin cache or running Codex runtime has been refreshed.

The plugin is provided as source for taking a settled spec through to executed work: PRD and issue publication, acceptance-check mapping, implementation planning and execution, tracker triage, plan queues, and spec-drift reconciliation. It is provided without warranty. You are responsible for what is published to your issue tracker, for the code an executed plan or issue produces, and for deciding what to merge, push, or release.

Plan Cycle actions are attended, and their tracker mutations and landings are approval-gated: nothing is posted to a tracker or merged without the user's approval or explicit instruction in the current turn, local commits follow each skill's documented default, and no skill pushes, opens a pull request, or publishes a release. Do not treat a published PRD, a labeled issue, an executed plan, or a locally merged queue plan as review, release, security, compliance, legal, or operational approval without the appropriate human and project-specific verification.

Installed-runtime behavior, cache refresh, marketplace setup, and runtime proof are separate operational steps from editing this source tree.
