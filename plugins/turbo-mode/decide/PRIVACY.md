# Decide Plugin Privacy Notice

This document describes the Decide plugin source package in this repository. It does not certify what any installed Codex runtime or plugin cache currently loads.

The Decide plugin provides instructions for taking a decision from a still-muddy want to a defensible choice: shaping the want (`outcome-shaping`), widening the option field (`ideate`), developing fixed options to comparable depth (`option-shaping`), choosing among comparable options (`making-recommendations`), settling a design before implementation (`design-exploration`), running that chain autonomously in one invocation (`deliberate`), cutting a shaped scope under a binding constraint (`scope-cut`), and capturing an already-made decision as a numbered ADR (`decision-record`). It does not create background files, register hooks, run services, or intentionally transmit content to a separate service by itself.

Decide requests may cause the runtime to read local repository files, git state, conversation context, and any artifact, path, or evidence the user names, and to write only what each skill documents: a shaping brief only when the user explicitly asks for one, placed per repo convention and left uncommitted (`outcome-shaping`); a design document on the user's approval (`design-exploration`); during a `deliberate` run, six Markdown stage files in a fresh directory under the runtime's scratch or temporary root, left in place so the user can read them and re-run from any stage, never under the working tree; an ADR file under `docs/adr/` plus, on a supersession, a `Status` line on the superseded record, or, on a narrowing that leaves the older record in force and where the repo's ADR convention carries dated amendment sections, one such section on the older record with its existing text unedited, committed locally (`decision-record`, which reads whatever source the user supplies: the live conversation, a pasted transcript, a PR thread); nothing else on disk. Content can leave this machine on these paths, each under the user's control: `making-recommendations` verifies unstable facts (current prices, laws, availability, schedules, APIs) with the runtime's search tools when the answer depends on them; `deliberate` performs web research only under evidence authorization echoed in its invocation contract; and `scope-cut` routes its deferred-item ledger to `triage` where that skill is available, which posts to the configured issue tracker only on approval. A `deliberate` run dispatches fresh stage subagents through the runtime, and each stage packet carries the decision frame, candidates, constraints, evidence identities, and prior artifacts its contract selects. Running `deliberate`'s bundled validator resolves its declared Python dependency through `uv`, which may download that package into uv's cache on first use; no conversation content travels with that request.

Codex, Claude, account handling, model requests, telemetry, synchronization, and any host application behavior are governed outside this local plugin document.

Review a design document, tracker item, or research authorization before approving it, especially when it may include private project details, file paths, customer data, credentials, or other sensitive information.
