# Pressure Test Plugin Terms

This document applies to local use of the Pressure Test plugin source package in this repository. Source edits here do not prove that an installed plugin cache or running Codex runtime has been refreshed.

The plugin is provided as source for pre-commitment challenge: interrogation, assumption registers, premortems, attacker modeling, and steelman briefs. It is provided without warranty. You are responsible for deciding what to do with the questions, assumptions, failure causes, attack paths, and arguments it produces; none of the five skills renders a verdict or makes the decision.

Pressure Test actions are attended and advisory: nothing is executed, published, or committed by a skill, and `red-team` describes attack paths without carrying any out. Do not treat a grilled plan, an empty premortem, or a ranked attack map as release, security, compliance, legal, or operational approval without the appropriate human and project-specific verification.

Installed-runtime behavior, cache refresh, marketplace setup, and runtime proof are separate operational steps from editing this source tree.
