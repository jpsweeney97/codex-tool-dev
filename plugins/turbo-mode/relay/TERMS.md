# Relay Plugin Terms

This document applies to local use of the Relay plugin source package in this repository. Source edits here do not prove that an installed plugin cache or running Codex runtime has been refreshed.

The plugin is provided as source for hand-carried transport between sessions: paste-packet composition and reply adjudication, sha-stamped packet files for sessions sharing a filesystem, and durable one-way commission prompts. It is provided without warranty. You are responsible for reading what you carry, for what the receiving session or model does with it, and for deciding which adjudicated findings to act on.

Relay actions are attended: no leg moves between sessions on its own, and the only writes are the packet and prompt files each skill documents, including the commit and push `stage-prompt` makes in the personal prompts repository. Do not treat an adjudicated reply as release, security, compliance, legal, or operational approval without the appropriate human and project-specific verification.

Installed-runtime behavior, cache refresh, marketplace setup, and runtime proof are separate operational steps from editing this source tree.
